# Histórias de usuário

| Cartão | História |
|---|---|
| Cadastro | Como visitante, quero criar uma conta com nome, e-mail, senha e papel, para usar o Pátio. |
| Login | Como usuário, quero entrar com e-mail e senha, para acessar meus grupos. |
| Criar grupo | Como usuário, quero criar um grupo e receber um código, para convidar minha turma. |
| Entrar em grupo | Como aluno, quero entrar em um grupo pelo código, para participar da conversa. |
| Enviar mensagem | Como membro, quero enviar texto e imagem no grupo, para conversar com a turma. |
| Receber mensagem | Como membro, quero ver as mensagens do grupo em ordem, para acompanhar a conversa. |
| Criar tags | Como professor, quero criar tags com nome e cor no grupo, para organizar os membros. |
| Aplicar tags | Como professor, quero aplicar tags nos membros, para identificar papéis como representante. |
| Quadro de avisos | Como professor ou gestão, quero publicar avisos com categoria e data, para comunicar a escola. |
| Ler avisos | Como aluno, quero ver os avisos dos meus grupos, para não perder provas e eventos. |
